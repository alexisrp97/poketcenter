# Poket Center

Tienda web estática de Poket Center: charms, peluches exclusivos y joyería de los Pokémon Center de Japón.

## Publicar en Render
1. En Render: **New → Static Site** (o **New → Blueprint**, que lee `render.yaml`).
2. Conecta este repositorio.
3. Build command: *(vacío)* · Publish directory: `.`
4. Cada `git push` a `main` vuelve a publicar la web.

## Editar productos y precios
Los productos están en `index.html`, en la lista `PRODUCTS` (busca `const PRODUCTS`). Las fotos van en `img/`.
